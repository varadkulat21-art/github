# Simple Interest Calculator

A Bash calculator that calculates simple interest from the principal, annual interest rate, and time period in years.

## Formula

`Simple Interest = (Principal × Annual Rate × Time) / 100`

## Run

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Example inputs: principal `1000`, rate `5`, time `2`. Expected simple interest: `100.00`.
